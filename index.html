    About the model & serving

    displayvalue PMTiles GPU colormapdataCOG HTTP RangeMapLibre GL

    One single-band float model becomes two files served from object storage with no tiling server: a value PMTiles that carries the suitability in the tile itself (read as a raster-dem source, coloured by viridis on the GPU), and a uint16 COG (with overviews) you can download and click-read in the browser.

    Why it stays fast: tiles are pre-cut with overviews and range-served, so the browser fetches a handful and the GPU draws and colours them, no server-side re-tiling, nothing re-rendered per request. Because the colour lives in a GPU ramp (Kyle Barron's COG-native argument), the colormap and the suitability threshold recolour live, no round-trip.

    The tradeoff, honestly: a value tile must be lossless (lossy compression would corrupt the value it carries), so it runs ~3× a lossy colour-baked tile. We pay transfer to gain live recolour and data-true display; the exact 4-dp value still comes from the COG.
